# Landing Page — опис дизайну (design spec)

Конкретний дизайн **цієї** сторінки, звідки ші будує розмітку/стилі. Читати в парі з:
- `design-ai-rules.md` — загальні правила дизайну;
- `client-design-brief.md` — палітра, шрифти, токени, сигнатура.

Якщо конфлікт: цей файл (спец сторінки) > бриф клієнта > загальні правила.

**Субʼєкт:** особистий лендінг **репетиторки з англійської**. Аудиторія — українська.
**Єдина ціль сторінки:** відвідувач **записується на безкоштовний пробний урок** (форма / месенджер).
Усе на сторінці працює на цю дію.

---

## 0. Концепт (art direction)

Тепла, редакційна, **людяна** мінімалістика. Сторінка тримається на типографіці й повітрі, а не на рамках і картках.

- **Сигнатурний прийом — маркер-хайлайт** світло-фіолетовим (`--accent`) на одному ключовому слові в заголовках. Тематично влучно: як виділення головного в конспекті. Це єдина «сміливість» — решта тиха.
- **Голос — Unbounded** великим кеглем на заголовках; **Montserrat** — спокійний текст.
- **Структура — хайрлайни (`--line`) і пробіл**, а не бордер-картки. Майже нульове заокруглення.
- **Колір дозовано:** тепла база `--bg`, near-black текст, світло-фіолетовий тільки на маркері/CTA/дрібних акцентах (правило 10%). Жодного оранжевого.
- **Один темний момент** на сторінці (секція контакту) — як навмисний контраст-«рамка».

---

## 1. Що НЕ так у поточному дизайні → як робимо інакше

Поточний варіант компетентний, але шаблонний. Змінюємо:

- ❌ Усе в бордер-картках (credentials-panel, languages-card, пілюлі, форма) → ✅ структура на **хайрлайн-лініях і повітрі**, картки прибираємо.
- ❌ Скляний blur sticky-хедер → ✅ чистий бар на `--bg` з тонкою лінією знизу.
- ❌ Капс-мікролейбли на кожній секції (eyebrow + section-tag всюди) → ✅ лишаємо 1–2 навмисні, решту прибираємо.
- ❌ Симетричні 50/50 гріди скрізь → ✅ **асиметрія**, сильний контраст масштабу.
- ❌ Багато дрібних пілюль-тегів (specialty/skill) → ✅ чисті інлайн-переліки типографікою.
- ❌ Розсіяний акцент → ✅ один сигнатурний маркер + Unbounded як голос.

---

## 2. Глобальна система

- Контейнер `--container-w` (1160px), поля 24px.
- Ритм секцій: `padding-block: 96px` (десктоп) / 64px (моб).
- Крок відступів: 8 · 16 · 24 · 32 · 48 · 64 · 96.
- Заокруглення: 0–4px (тримаємо крихкий, «редакційний» край).
- Роздільники: `1px solid var(--line)`. Бордер-картки — лише де без них ніяк (форма).
- **Типо-шкала:**
    - Hero H1: `clamp(2.75rem, 6vw, 5rem)`, `line-height: 0.98`, Unbounded 800, uppercase, `letter-spacing: -0.02em`.
    - H2 секцій: `clamp(1.75rem, 3.4vw, 2.75rem)`.
    - Body: 16–18px, Montserrat, `line-height: 1.6`, довжина рядка ≤ 65ch.
- **Маркер (сигнатура):**
  ```css
  .mark {
    background: var(--accent);
    color: var(--text);
    padding: 0 .18em;
    box-decoration-break: clone;
  }
  ```
  Правило: **один маркер на заголовок**, на смисловому слові («ЗАГОВОРИШ», «ВІЛЬНО», «ПРОБНИЙ»).

---

## 3. Секції

Порядок і зміст — під ціль «записати на пробний». Копірайт нижче — **приклад-плейсхолдер**.

### 3.1 Nav
Чистий бар на `--bg`, тонка лінія знизу. Ліворуч — імʼя/лого (Unbounded, маленький). Праворуч — 3 якорі (Про мене · Як проходять уроки · Відгуки) + кнопка `Пробний урок`. Без скла/тіней.

```
┌───────────────────────────────────────────────┐
│  ІМʼЯ         Про мене  Уроки  Відгуки   [Пробний] │
└───────────────────────────────────────────────┘
```

### 3.2 Hero (головний екран)
**Асиметрія:** великий заголовок веде, фото — підтримка.

```
┌───────────────────────────────────────────────┐
│  онлайн-уроки англійської                       │  ← дрібний eyebrow (стримано)
│                                                 │
│  АНГЛІЙСЬКА, ЯКОЮ                                │  ← Unbounded, дуже великий
│  ТИ [ЗАГОВОРИШ]                                  │  ← маркер на слові
│                                                 │
│  ┌───────────────┐   ┌─────────────────────┐    │
│  │ Лід 1–2 речення│   │                     │    │
│  │ 2 CTA          │   │   ФОТО ВИКЛАДАЧКИ    │    │
│  │ рядок довіри   │   │   (чиста рамка)      │    │
│  └───────────────┘   └─────────────────────┘    │
└───────────────────────────────────────────────┘
```

- **H1** (приклад): «АНГЛІЙСЬКА, ЯКОЮ ТИ **ЗАГОВОРИШ**» — маркер на «ЗАГОВОРИШ».
- **Лід:** «Індивідуальні онлайн-уроки під твою ціль — розмова, іспити, робота. Перший урок безкоштовний.»
- **CTA:** `Записатися на пробний` (primary, `--accent-deep`) + `Як проходять уроки` (ghost).
- **Рядок довіри** (тонкий, без пілюль): `CELTA · 200+ учнів · 6 років практики`.
- **Фото:** реальне, тепле, у чистій рамці `--line`, без важких тіней. Це LCP → не лінивити, `fetchpriority="high"`.

### 3.3 Trust / цифри
Без бордер-комірок зі стінками. Тонка стрічка на `--surface`, великі числа Unbounded + дрібні лейбли, розділені повітрям (або тонкими хайрлайнами).

```
   200+          6 років        CELTA/TESOL       95%
   учнів         практики       сертифікати       лишаються після пробного
```

### 3.4 Про викладачку
Асиметрія: ліворуч великий людяний абзац (від першої особи), праворуч — тихий хайрлайн-список фактів (без картки). Одне слово в тексті — під маркером.

```
┌──────────────────────────┬──────────────────┐
│ Велике інтро, 2–3 абзаци  │ — Підхід          │
│ від першої особи, тепле.  │ — Формат уроків   │
│ Одне слово [маркером].    │ — Матеріали       │
└──────────────────────────┴──────────────────┘
```

### 3.5 Сертифікати / кваліфікація
Простий хайрлайн-список: `рік — сертифікат — орган`. Довіру дає типографіка, не рамки.

```
2021 ── CELTA (Cambridge)
2019 ── IELTS 8.5
2018 ── Диплом, філологія
```

### 3.6 Як проходять уроки (кроки)
Це **справжня послідовність** → номери доречні. Великі Unbounded-номери `01–04`, хайрлайн між кроками. Пілюлі-теги звідси прибрати.

```
01 ── Залиш заявку        Пишеш у формі/телеграм, домовляємось про час.
02 ── Безкоштовний пробний Знайомимось, визначаємо ціль і рівень.
03 ── План і графік        Підбираємо програму та зручний розклад.
04 ── Вчимося              Регулярні уроки, відстеження прогресу.
```

### 3.7 Досвід (таймлайн)
Вертикальний таймлайн лишаємо, але тихіший: хайрлайн-лінія, маленька **квадратна** крапка `--accent-deep`, дата підкреслена тонкою акцент-лінією. Без зайвих капслейблів.

### 3.8 Спеціалізації (з чим працює)
Замість пілюль — чистий інлайн-перелік Unbounded легшої ваги або 2–3 колонки. Одну позицію можна виділити маркером.

```
Розмовна англійська · Підготовка до IELTS / TOEFL ·
Бізнес-англійська · Англійська для дітей · Граматика з нуля
```

### 3.9 Мови
Тихий хайрлайн-список `мова — рівень`, без картки.

```
Українська ── рідна
Англійська ── C2
Польська  ── B2
```

### 3.10 Фінальний CTA
Велика Unbounded-фраза з маркером + одна кнопка. На `--surface`, обрамлена хайрлайнами. Світло-фіолетовим **не заливати** всю площу (правило 10%).

```
        ГОТОВА ПОЧАТИ [ГОВОРИТИ]?
        [ Записатися на пробний ]
```

### 3.11 Контакт (запис на урок) — темний момент
Єдина темна секція: фон `--text`, текст `--bg`, акценти `--accent`. Це навмисна «рамка»-контраст (відсилання до референсу VinylUA).

- Ліворуч: короткий заголовок + месенджер-лінки (Telegram, Instagram) — для репетитора це головний канал.
- Праворуч: компактна форма на світлому: `Імʼя`, `Контакт (email/телеграм)`, `Твоя ціль` (textarea), кнопка `Записатися на пробний`.
- Фокус інпутів — `--accent-deep`. Мінімум лейблів-капсу.

```
┌───────────────────────────┬──────────────────┐
│ Напиши — відповім швидко.  │ [ Імʼя         ]  │
│  ▸ Telegram                │ [ Контакт      ]  │
│  ▸ Instagram               │ [ Ціль…        ]  │
│                            │ [ Записатися ]    │
└───────────────────────────┴──────────────────┘  (dark)
```

### 3.12 Footer
Тонкий, хайрлайн зверху: імʼя · рік · соц-лінки. Uppercase дрібним, `--muted`.

---

## 4. Рух (стримано)

- Скрол-ревіл секцій: легкий fade + translateY (8–16px), швидко.
- **Сигнатурний момент:** маркер у hero «промальовується» зліва-направо на завантаженні (один раз, ~500ms).
- Hover: CTA (зміна фону), лінки (колір → `--accent-deep`).
- Обовʼязково `@media (prefers-reduced-motion: reduce)` — усе вимикається.

---

## 5. Адаптив

- < 960px: hero в одну колонку, **фото над лідом**; про-секція та досвід — одна колонка.
- < 720px: nav згортається в бургер; цифри — 2 колонки; кроки — вертикально.
- < 480px: секції 64px; CTA на всю ширину; цифри в стовпчик.
- H1 керується `clamp()`, не ламається на 360px.

---

## 6. Чекліст відповідності брифу

- [ ] Один сигнатурний прийом — маркер `--accent` на одному слові
- [ ] Unbounded (дисплей) + Montserrat (текст), кирилиця
- [ ] Тепла база + світло-фіолетовий дозовано (≤10%), **без оранжевого**
- [ ] Структура на хайрлайнах і повітрі, не на бордер-картках
- [ ] Асиметрія + сильний контраст масштабу, а не симетричні гріди
- [ ] Один навмисний темний момент (контакт)
- [ ] Кожна секція веде до одного CTA — «записатися на пробний»
- [ ] LCP-фото не лінивиться; `prefers-reduced-motion` враховано
- [ ] Дизайн не скочується в жоден із трьох ші-дефолтів
