# Client Design Brief — вподобання для ші

Конкретні вподобання клієнта для лендінгу. Використовувати **разом із** `design.rules.md`: там загальні правила, тут — фірмовий напрям цього клієнта. Якщо є конфлікт — цей файл має пріоритет.

> Джерела: 2 референси по кольору + 2 референси по типографіці (нижче) + усні побажання клієнта.

---

## 1. Загальний напрям

- **Мінімалізм.** Багато повітря, мало елементів, типографіка несе основне навантаження. Не максималізм, не «насичено».
- **Тепла нейтральна база + один фірмовий акцент.** Акцент — **світло-фіолетовий**, дозовано.
- **Типографіка = головний прийом.** Великий жирний гротеск, характерна подача заголовків (складання літер стовпчиком).
- **Дисципліна.** Мінімум декору, хайрлайн-структура, майже нульове заокруглення.

---

## 2. Кольори

### Головне правило
- Фірмовий акцент — **світло-фіолетовий**.
- **Оранжевий заборонено.** Сюди ж — теплий цегляно-червоний (як `#BB210C` з референсу): читається як оранжевий → не використовуємо.
- Палітра **обмежена**: тепла нейтральна база + 1 акцент. Другий колір — лише за крайньої потреби, приглушено.

### Рекомендована палітра (ролі + hex)

| Роль | Hex | Призначення |
|---|---|---|
| Base / фон | `#F5F1EA` | тепла світла база (від беж-референсу, трохи чистіша) |
| Surface | `#FFFFFF` | картки, підняті поверхні |
| Text | `#2A2622` | основний текст (теплий near-black) |
| Muted | `#6B655D` | другорядний текст, підписи |
| **Accent (light purple)** | `#B7A6E8` | фірмовий акцент: маркер-хайлайти, заливки, підкреслення |
| Accent deep | `#6E5AA8` | коли на акценті потрібен білий текст (напр. CTA) — щоб пройти контраст AA |
| Line | `#E3DCD0` | хайрлайн-роздільники |

> `#B7A6E8` — це «світлий» фіолетовий для настрою (хайлайти, фони-плашки). Для клікабельних елементів із білим текстом бери глибший `#6E5AA8` (контраст ≥ 4.5:1). Альтернатива в дусі мінімалізму: **світло-фіолетова плашка + темний текст** — тоді акцент лишається світлим і на брифі.

```css
:root {
  --bg:          #F5F1EA;
  --surface:     #FFFFFF;
  --text:        #2A2622;
  --muted:       #6B655D;
  --accent:      #B7A6E8;   /* світло-фіолетовий — сигнатура */
  --accent-deep: #6E5AA8;   /* для білого тексту на акценті */
  --line:        #E3DCD0;
}
```

✅ Акцент лише на дії/ключовому: CTA, підкреслення слова, маркер-плашка.
❌ Не заливай акцентом великі площі — світло-фіолетовий працює саме як рідкісний акцент (правило 10%).
❌ Ніякого оранжевого/цегляно-червоного.

---

## 3. Референси по кольору (що саме беремо)

**`color_1`** — дизайн-система з приглушеною палітрою на беж-фоні (`#EDE0D0`), теплий темний текст `#524C46`, приглушений синій `#6F8DB5`, олива `#C9BB5F`, стиль «прямокутники з рівними краями + кола».
- ✅ Беремо: тепла нейтральна база, **низька насиченість** усіх кольорів, дисциплінований UI-kit, приглушений синій `#6F8DB5` — як **опціональний** холодний support до фіолетового (дуже дозовано).
- ❌ Не беремо: теплий червоний `#BB210C` (оранжевий) — прибрано.

**`color_2` (VinylUA)** — темна секція-рамка обрамляє світлий (кремовий) контент, один яскравий акцент-«маркер» (хайлайтер), редакторський serif-дисплей.
- ✅ Беремо: прийом **«маркер-хайлайт» на одному слові** (у нас — світло-фіолетовий замість жовтого), сильний контраст темної рамки й світлого контенту як спосіб фокусу.

---

## 4. Типографіка та акценти шрифтів

Джерело — **`text_focus_1` / `text_focus_2`** (брендинг Daniels / 1 Spadina, University of Toronto): жирний гротеск, чорне на білому, акцентний колір **лише** на одному слові, а головний прийом — **складання літер стовпчиком** (`D / AN / IELS`, `1 / SPAD / INA`).

### Правила
- **Display — жирний гротеск**, щільний трекінг, аптеркейс. Літери можуть **складатися стовпчиком** як фірмовий прийом.
    - Шрифт: **`Unbounded`** (Black/ExtraBold) — варіативний гротеск із повною кирилицею й українськими літерами (ґ, є, і, ї), ідеальний під великий hero.
    - ⚠️ `Space Grotesk`, `Archivo`, `Inter Tight` на Google Fonts **не мають кирилиці** (лише latin/latin-ext/vietnamese) → для українського заголовка **не використовувати**.
- **Body — чистий нейтральний сан-серіф.** `Montserrat` (з референсу `color_1`) або `Inter`. Розмір body ~16px, підписи ~14px.
- **Акцентний колір — лише на одному ключовому слові** заголовка (світло-фіолетовим), не на всьому рядку.
- Максимум 2 сімейства: display + body. Serif із `color_1` (Kyiv*Type Serif) — **не** беремо, бо напрям типографіки заданий гротескний (Daniels).
- Сильний контраст масштабу: hero-заголовок помітно більший за все інше; проміжних розмірів мало.

```css
:root {
  --font-display: "Unbounded", system-ui, sans-serif; /* bold grotesk, кирилиця */
  --font-body:    "Montserrat", "Inter", system-ui, sans-serif;
}

/* Сигнатурний прийом: складання літер + акцент на слові */
.hero__title {
  font-family: var(--font-display);
  font-weight: 800;
  text-transform: uppercase;
  letter-spacing: -0.01em;
  line-height: 0.95;   /* щільно, для складання стовпчиком */
}
.hero__title .accent { color: var(--accent-deep); }  /* лише одне слово */
```

✅ Заголовок як головний візуал сторінки, з характерним складанням літер.
❌ Не роби акцентним кольором увесь заголовок; не мішай serif + grotesk у дисплеї.

---

## 5. Сигнатурний прийом (одна річ, що запам'ятається)

Обери **одне** з двох (не обидва одночасно):
1. **Складання літер стовпчиком** у hero (від Daniels) — велике, жирне, чорне, з одним словом/буквою в світло-фіолетовому.
2. **Маркер-хайлайт** світло-фіолетовим на ключовому слові (від VinylUA) — як виділення текстовим маркером.

Решту лендінгу тримай тихою: нейтральна база, багато повітря, хайрлайни, майже без заокруглень.

---

## 6. Do / Don't (звід)

**Do**
- ✅ Мінімалізм, багато білого простору
- ✅ Тепла нейтральна база (`#F5F1EA`) + світло-фіолетовий акцент
- ✅ Жирний гротеск як головний прийом, складання літер
- ✅ Акцент (колір/маркер) — рідко й точково
- ✅ Хайрлайн-роздільники, near-zero border-radius
- ✅ Приглушений синій `#6F8DB5` — лише як опціональний холодний support

**Don't**
- ❌ Оранжевий і теплий цегляно-червоний (`#BB210C`)
- ❌ Максималізм, багато кольорів, важкі градієнти
- ❌ Акцентний колір на великих площах або на всьому заголовку
- ❌ Serif-дисплей / змішування serif+grotesk у заголовках
- ❌ Декор без функції, зайві заокруглення й тіні

## 7. Готові токени (скопіювати в проєкт)

```css
:root {
  /* Color */
  --bg:          #F5F1EA;
  --surface:     #FFFFFF;
  --text:        #2A2622;
  --muted:       #6B655D;
  --accent:      #B7A6E8;   /* світло-фіолетовий */
  --accent-deep: #6E5AA8;   /* для білого тексту на акценті */
  --support:     #6F8DB5;   /* опціонально, дуже дозовано */
  --line:        #E3DCD0;

  /* Type */
  --font-display: "Unbounded", system-ui, sans-serif;
  --font-body:    "Montserrat", "Inter", system-ui, sans-serif;

  /* Radius / spacing (мінімалізм) */
  --radius: 4px;
  --space:  8px;  /* крок сітки: 8,16,24,32,48,64,96 */
}
```

## 8. Підключення шрифтів

**Шрифти:** `Unbounded` (display) + `Montserrat` (body). Обидва — з повною кирилицею.
Ваги: Unbounded — 700/800/900; Montserrat — 400/500/600/700.

### Варіант A — Google Fonts (найпростіше)

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="stylesheet"
  href="https://fonts.googleapis.com/css2?family=Montserrat:wght@400;500;600;700&family=Unbounded:wght@700;800;900&display=swap">
```

### Варіант B — self-host (краще для швидкості, рекомендовано для Angular)

```bash
npm i @fontsource-variable/unbounded @fontsource/montserrat
```

```ts
// у global styles / styles.ts
import '@fontsource-variable/unbounded';   // варіативний, усі ваги
import '@fontsource/montserrat/400.css';
import '@fontsource/montserrat/500.css';
import '@fontsource/montserrat/600.css';
import '@fontsource/montserrat/700.css';
```

**Правила підключення:**
- `display=swap`, щоб текст не блокувався рендером.
- Якщо hero-заголовок — це LCP, **preload** його woff2 (не лінивити LCP-ресурс, як у SEO-файлі).
- Тягнути лише потрібні ваги, не всю родину.

---

> Субʼєкт лендінгу клієнт поки не вказав — напрям вище про **естетику** (колір + тип + мінімалізм), не про тему. Коли зʼявиться продукт/тема, підлаштуй сигнатуру під нього, не змінюючи палітру й типо-напрям.
